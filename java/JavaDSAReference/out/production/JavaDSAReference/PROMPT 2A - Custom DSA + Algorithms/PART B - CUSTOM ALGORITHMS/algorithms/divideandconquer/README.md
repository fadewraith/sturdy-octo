# DIVIDE & CONQUER (Sorting Note)

Please note that the two most famous Divide & Conquer algorithms:
1. **Merge Sort**
2. **Quick Sort**

Have already been extensively covered and fully implemented in the **`algorithms/sorting`** package (Part B, Item 1).

*   `MergeSort.java` demonstrates perfectly splitting an array into single elements and merging them back together.
*   `QuickSort.java` demonstrates partitioning around a pivot and dividing the problem space.

See those files for full implementations!
